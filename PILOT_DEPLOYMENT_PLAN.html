UFCL Mobile — Pilot Deployment Plan

v1.0.0  |  Stage 2 — Limited rollout to 9 pilot users  |  Target: 2026-07-01 to 2026-07-14
Why a pilot? Real-world usage on actual data reveals issues that UAT cannot find. A 9-person pilot for 1–2 weeks gives you the issues that will affect everyone — caught before they hit 60+ users.

2. Pilot Installation Steps (per user)

  1. IT installs TLS certificate on device (Settings → Security → Install cert → select ufcl.crt)
  2. Enable "Install from unknown sources" (Settings → Apps → Special app access)
  3. Transfer APK to device via USB cable or shared folder
  4. Tap APK file → Install → Open
  5. Verify launcher icon shows "UFCL" (not "UFCL Dev")
  6. Login with assigned credentials
  7. Verify navigator tabs match role (see User Manual §2)
  8. Create one test record in each module to confirm connectivity
  9. Demonstrate offline mode: airplane mode → create record → reconnect → verify sync
Note: If the device shows a certificate warning on first load, the TLS cert was not installed correctly. Repeat step 1 before proceeding.

3. What to Tell Pilot Users

Give each pilot user this brief:

  • Use the app for real work — enter your actual daily records, not test data
  • Report anything that feels wrong — wrong calculations, missing data, confusing screens, slow loading, unexpected errors
  • Report what you wish was different — missing fields, workflow that doesn't match how you actually work
  • Try going offline (airplane mode) while creating records — check that they sync when you reconnect
  • Check My Requests to see your submitted records and their approval status
  • Contact IT immediately if you cannot log in or if data disappears

4. Feedback Collection

Collect feedback in three ways:

  1. WhatsApp group — create a "UFCL App Pilot" group, all 9 users + IT lead. Users report issues immediately as they happen.
  2. End-of-day check-in — brief 5-minute call or message each evening for first 3 days
  3. Weekly survey — short form at end of week 1 (see Section 5)

5. Feedback Form (Week 1)

Send to all pilot users at end of Week 1:

  1. How easy was it to log in and find your screens? (1=very hard, 5=very easy)
  2. Were there any records you could not enter that you expected to?
  3. Did the offline mode work when you had no network?
  4. Did your submitted records appear correctly in My Requests?
  5. Was anything slow or took too long?
  6. What is the most important thing that needs to change before full rollout?
  7. Would you recommend this to a colleague? (Yes / With some changes / No)

8. Pilot Exit Criteria

The pilot is considered successful and ready for Stage 3 full rollout when:

  • Zero CRITICAL bugs remain open
  • Zero MAJOR bugs remain open
  • All 9 pilot users have submitted at least 3 days of real records
  • Offline sync has been tested on at least 2 devices
  • Server has been running continuously for at least 7 days with PM2 restart count = 0
  • CEO signs off on pilot completion
