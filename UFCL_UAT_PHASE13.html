Bug Severity Classification

CRITICAL

  • Cannot login or session lost
  • Data loss or corruption
  • App crash
  • Wrong role permissions
  • Wrong workshop data visible
Fix immediately — blocks launch

MAJOR

  • Workflow blocked or unusable
  • Incorrect calculations shown
  • Offline sync failure
  • Approval chain broken
  • Missing required data in list
Fix before production

MINOR

  • Layout / alignment issue
  • Wrong colour or icon
  • Typo in label or message
  • Cosmetic difference from design
Fix in v1.1 — does not block

IT Setup — Complete Before Handing to Testers

  1. Install the release APK on each test device. Verify the app opens without errors.
  2. Create one test account per role being tested. Confirm each can login.
  3. For workshop isolation test: create harvest_sup_A (Workshop A) and harvest_sup_B (Workshop B). Then, as admin or harvest leader, create 3 harvest entries tagged to Workshop A and 3 to Workshop B.
  4. For sawmill calculations: pre-create a sawmill production entry with known values (e.g., logs_received=100, ready_for_production=80). Confirm the expected timber volume formula output.
  5. For the approval chain test: submit one material request and one casual labour entry as a harvest leader before the CEO/Operations tester begins their session.
  6. For POD test: create a delivery order in Delivered status before the logistics tester starts.
  7. Confirm the server is responding: curl https://192.168.1.5/api/ready
  8. Confirm backups are running: tail -3 /opt/ufcl-backups/backup.log
