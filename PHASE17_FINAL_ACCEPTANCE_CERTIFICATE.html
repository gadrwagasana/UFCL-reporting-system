System Description

UFCL Mobile is a role-based, offline-first Android ERP application that digitises daily reporting across all operational departments of Uganda Forest Corporation Limited, replacing all paper-based records and Excel spreadsheets. The system integrates with a centrally hosted Express.js backend API and PostgreSQL database over a secure LAN HTTPS connection.

Accepted Limitations (v1.1 Backlog)

The following minor items were identified during audit and are accepted as non-blocking for v1.0.0 production use. They will be addressed in v1.1.0.

  • android:usesCleartextTraffic=true remains in manifest — all production URLs are HTTPS; flag is vestigial (V11-01)
  • Mechanic role has no Profile tab (V11-02)
  • logistics-officer sees Vehicle Fuel tab but receives 403 — security correct, UX gap (V11-08)
  • CI triggers on all mobile/** pushes, not version tags only (V11-03)
  • No unit test coverage for auth flows and data.js (V11-07)
