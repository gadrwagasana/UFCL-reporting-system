G. Backup & Restore Guide (summary)

Full procedure is in UFCL_ADMIN_MANUAL.html Section 7.

OperationCommandSchedule
Database backup bash tools/backup.sh Daily 02:00 (cron); manual anytime
Database restore gunzip -c db-<date>.sql.gz | psql -U postgres -d ufcl_production On demand
Backup location /opt/ufcl-backups/daily/, weekly/, monthly/ —
Retention 7 days daily, 4 weeks weekly, 12 months monthly Automatic rotation
Integrity check gzip --test /opt/ufcl-backups/daily/db-<date>.sql.gz Automatic after each backup

H. Disaster Recovery Guide (summary)

Full procedure is in UFCL_ADMIN_MANUAL.html Section 9.

ScenarioRecovery pathRTO
API process crash PM2 auto-restarts (max 10 attempts). If fails: pm2 restart mobile-api < 30 seconds
Server reboot PM2 startup hook + nginx/postgresql systemd auto-start < 2 minutes
Database corruption Restore from last daily backup (max 24h data loss) < 30 minutes
Server hardware failure New server: run LAUNCH_CHECKLIST + restore backup < 4 hours
APK corruption / bad release Revert version.json to previous; sideload old APK to affected devices < 1 hour
Stolen/lost device Admin deactivates user in database; JWT becomes invalid at next request < 5 minutes
